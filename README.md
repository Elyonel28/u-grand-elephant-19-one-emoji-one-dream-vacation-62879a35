One emoji, one dream vacation: 🗻 — Mount Fuji at dawn. One unmistakable place, a postcard a stranger can see at a glance, and a trip people actually dream of booking.

## Run it

```sh
node main.ts
```

The program writes exactly one emoji to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT`).

## Entry

`output/entry.txt` contains a single character: 🗻 (U+1F5FB MOUNT FUJI, 1 code point, 4 bytes UTF-8, no trailing newline).
